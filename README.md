# Zyn消息防撤回

一个纯本地运行的安卓「消息撤回查看器」：用通知监听把收到的消息先存一份，等微信/QQ 出现「XX撤回了一条消息」时，用正则认出撤回者，再把这个人撤回前的那条内容还原出来。

- 包名 `com.zyn.keeper`，版本 1.0.2
- **最低支持 Android 5.0（API 21）**，编译/目标 SDK 34（Android 14），在 15/16 上同样可用
- 数据只存在本机 `zyn.db`；网络权限仅用于「检查更新 / 下载新版本」，不上传任何聊天内容
- UI 走 Claude 网页版那种米白底 + 陶土橙 + 衬线标题的极简风格

---

## 一、它是怎么工作的

```
通知栏 → NotificationListenerService（捕获）
        ├─ 普通消息：昵称 + 内容 → 直接落库（notices 表）
        └─ 撤回提示：正则命中「XX撤回了一条消息」
                      └─ 取出「XX」
                          └─ 在同一会话、同一发送者、回溯窗口内
                              └─ 查最近一条消息（notices 表）→ 生成撤回事件（recalls 表）
                                  └─ 悬浮窗 / 通知栏提醒
```

**为什么必须自己存一份历史？**
安卓系统「设置 → 通知 → 通知历史」那个历史库（`notification_history`）属于系统应用，第三方 App 没有读取权限，`NotificationListenerService` 只能拿到「当前活跃通知」。所以 Zyn 自己建了一份本地历史：监听开启期间收到的每条通知都会留档，撤回时才能反查出上一条。**没开监听的那段时间的撤回，任何方案都还原不了。**

## 二、安装

1. 拷 `Zyn消息防撤回-v1.0.2.apk` 到手机，点安装（首次需允许「安装未知来源应用」）。
2. 打开 App，进入「状态」页，按顺序把权限点亮。

## 三、首次配置，必要

## 四、功能清单

**撤回记录**
- 卡片式时间线：应用、会话、撤回者、被撤回内容、命中规则
- 点击看全文，一键复制、删除
- 没抓到原文的撤回也会记一条（提示「未捕获到原消息」）

**消息历史**
- 全部通知留档，支持按会话 / 用户 / 内容搜索

**识别规则（可编辑 + 可测试）**
- 内置微信、QQ 两条默认开启的规则，另有企业微信 / 钉钉 / Telegram 三条默认关闭
- 每条规则可改：包名正则、撤回提示正则、撤回者分组号、发送者正则、发送者/内容分组、自己正则
- 内置「正则测试」输入框：改完立刻喂一条样例文本验证，命中会显示提取到的撤回者

**提醒**
- 悬浮窗卡片（不透明度、停留秒数可调）
- 通知栏提醒（提示音 / 震动 / 是否显示内容可调）

**设置（30+ 项开关，全部默认已调到「最稳」）**
- 捕获：总开关、监听所有应用、记录普通消息、自动正则、自动提取发送者、忽略自己撤回、记录未知撤回、跳过折叠通知、**忽略常驻通知**、**排除的应用**、启动时导入当前通知、回溯窗口
- 提醒：悬浮窗、通知、显示内容、提示音、震动、停留时长、不透明度
- 保活：前台服务、开机自启、定时唤醒、WorkManager 心跳
- 数据：保留天数、最多条数、自动清理、导出 JSON / CSV、清理误记的撤回提示、清空

**状态页**
- 监听状态灯、最后捕获时间、消息数 / 撤回数 / 占用
- 六项权限逐条检测 + 一键跳转
- 重启守护、重新授权

## 五、正则说明（想自己调的时候看）

默认撤回正则（微信 / QQ 通用）：

```
^\s*(?:[^：:\n]{1,30}[：:]\s*)?(.{1,32}?)\s*撤回了一条消息[^\n]{0,26}$
```

- 第 1 个分组就是撤回者昵称，能吃掉「群名: 张三撤回了一条消息」这种带会话前缀的写法；
- 尾部用 `[^\n]{0,26}` 容错，能吃掉 QQ 的真实文案：`对方撤回了一条消息，你猜猜撤回了什么。`
- 能匹配：`张三撤回了一条消息`、`张三 撤回了一条消息`、`你撤回了一条消息`、`对方撤回了一条消息`、`张三撤回了一条消息。`、`张三撤回了一条消息，后面还有提示语`
- 尾部全角冒号（`张三：撤回了一条消息`）会在解析时被自动去掉。

普通消息正则（拆发送者与正文）：

```
^([^：:\n]{1,24})[：:]\s*(\S[\s\S]*)$
```

匹配 `李四: 晚上8点开会` → 发送者 `李四`，正文 `晚上8点开会`；私聊没有前缀时自动退回用会话名当发送者。

「对方 / 某人 / TA」这类称呼会映射成会话名来查历史，避免查不到人。

## 六、保活策略（多层叠加）

1. **HOME 身份**（可选）：桌面级进程优先级。
2. **前台服务**：一条最低优先级常驻通知，`specialUse` 类型，适配 Android 14 的前台服务新规。
3. **AlarmManager 定时唤醒**：每 15 分钟检查一次，进程被杀会被拉回。
4. **WorkManager 周期任务**：15 分钟一次，系统级调度，顺带做数据清理和断连提示。
5. **开机自启 / 应用更新后自启**：`BOOT_COMPLETED`、`MY_PACKAGE_REPLACED`。
6. **从最近任务划掉后 5 秒自唤醒**：`onTaskRemoved` 里补一个闹钟。
7. **电池优化白名单 + 厂商自启动引导**（需手动点）。

> 各家 ROM 的杀后台策略差异很大，能全开就全开；至少第 1、2、3 项别关。

## 八、已知限制（先看这段，能省很多困惑）

1. **系统通知历史读不到**：第三方 App 无权访问，Zyn 用的是自建库，所以「装完立刻翻旧账」是翻不到的，只能从现在开始积累。
2. **微信私聊撤回往往不发通知**：微信撤回时会撤销原通知，不一定再发一条「撤回了一条消息」。群聊里通常有。这是微信侧的行为，规则再准也变不出数据。
3. **部分 ROM 会折叠通知正文**：MIUI/ColorOS 等在「通知折叠」「隐藏消息内容」开启时，监听只能拿到「你收到一条消息」。务必在微信/QQ 里打开「显示消息详情」。
4. **同名/昵称歧义**：群里有重名或昵称带空格时，可能归属错，属正则固有局限，可在规则里自行收紧。
5. **`QUERY_ALL_PACKAGES`**：为了让应用名能正确显示，声明了该权限。不上架 Google Play 的话没有影响。
6. **只是工具，别拿去做不该做的事**：仅用于自己手机上、自己收到的消息留档，请遵守微信/QQ 用户协议与当地法律。
